# Single Exclusive Mode (новый режим рядом с паками)

Паки (8 SFW + 23 NSFW) остаются как есть — «Pack Mode (Legacy)». Добавляется второй режим, переключение одной кнопкой вверху.

## Что увидит пользователь

1. **Переключатель режимов** в шапке: «Отдельные изображения» / «Паки». Настройки хранятся отдельно для каждого режима.
2. **Новая страница «Серия»** — шаги по порядку:
   - **Сцена** — одна на всю серию: название, фон, композиция (можно взять из библиотеки или вписать вручную).
   - **Персонажи** — список: из библиотеки стилей, загрузкой TXT/CSV (по имени в строке) или вручную. Порядок можно менять, удалять.
   - **Генерация** — по 3 варианта на персонажа (число настраивается). Выбираю лучший одним тапом или прошу «ещё 3».
   - **Апскейл** выбранного — автоматически после выбора (переключатель), до разрешения из настроек.
   - **Редактор цензуры** для превью: кисть размытия, прямоугольник, мозаика, заливка; размер и сила; отменить/очистить. Работает в браузере на телефоне.
   - **Подготовка к публикации**: публичное превью (с цензурой, уменьшенное, с водяным знаком) и оригинал без цензуры.
3. **Очередь персонажей** со статусами: ожидает → генерация (1/3) → выбор → апскейл → готово → загружено.
4. **Прогресс серии** — кольцо «3/10 готово» и счётчики по статусам.
5. **Глобальная нумерация** — следующий номер (#4, можно изменить), шаблон названия `EXCLUSIVE ADOPT #{number} — {character}`, теги по умолчанию (`{character}`, вид, свои).

## Агент на ПК

- Берёт задания серии так же, как сейчас (Forge API, по одному кадру, повторы, восстановление после перезапуска).
- Промпт = промпт персонажа + текст сцены серии.
- После выбора — апскейл оригинала, сохранение на ПК в папку `exclusives/<номер>_<персонаж>`.
- Превью с цензурой (сделанное на сайте) загружается в Sta.sh/DeviantArt с названием по шаблону и тегами.

## Оригинал для покупателя: ограничение

У DeviantArt нет открытого способа прикрепить файл эксклюзива к работе автоматически: «Submit as Exclusive» и прикрепление файла для покупателя есть только в их интерфейсе. Предлагаю:
- **Сейчас**: агент кладёт оригинал на ПК и, по желанию, временно в облако, чтобы его можно было скачать на телефон и прикрепить через Edit (как с архивами паков). Удалить из облака — одной кнопкой.
- **Позже, отдельным шагом (по желанию)**: экспериментальная автоматизация через окно браузера на ПК, которая сама открывает Edit и прикрепляет файл. Может сломаться, если DeviantArt поменяет свою страницу, поэтому только как опция.

## Что не меняется

Паки, отбор 8/23, буфер 6 кадров, причины отказа, сцены/позы, Observer API, датасет.

## Технические детали

- Новые таблицы: `series` (сцена, режим, шаблон названия, теги, следующий номер, настройки апскейла/превью), `series_items` (персонаж, порядок, статус, выбранный кадр, номер, путь к оригиналу, путь к превью). В `images` и `generation_jobs` добавляется `series_item_id` (nullable). RLS по владельцу.
- `job/claim`: если активна серия — выдаёт задания для текущего персонажа, пока не будет N вариантов; иначе старая логика паков.
- Новые agent-маршруты: `series/upscale` (выдача выбранного оригинала), `series/preview` (signed upload/download превью), статусы элемента.
- Редактор цензуры — canvas на клиенте, результат загружается в приватный bucket `previews`.
- Переключатель режима хранится в профиле пользователя (`user_settings.mode`).
- Агент: новая ветка обработки `series` в `furry_agent.py`, legacy-режимы не трогаются.
- Делать поэтапно: 1) таблицы + страница серии + генерация/выбор; 2) апскейл + оригинал на ПК; 3) редактор цензуры + загрузка превью на DA; 4) нумерация/шаблоны.
