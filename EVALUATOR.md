# AI-отборщик кадров (EVALUATOR)

Документ описывает данные и архитектуру будущего автоматического отборщика.
**Реализация AI пока не ведётся** — текущий отбор полностью ручной.

## 1. Цель

Снизить ручную нагрузку: предлагать решение «годится / мимо» для каждого
сгенерированного кадра, сохраняя за человеком последнее слово.

## 2. Какие данные собираем

Для каждого кадра:

- персонаж и этап (SFW / NSFW);
- параметры генерации: промпт, негативный промпт, seed, width, height, steps,
  CFG, sampler, style (`generation_*`, `generation_settings`);
- решение человека: `status` (approved / rejected), `decision_source`,
  `reviewed_at`;
- причины отказа: `reject_reasons text[]`, свободный комментарий `reject_note`;
- поля под будущую автооценку: `ai_decision`, `ai_score`, `ai_details`.

Сами изображения лежат в Storage (`previews`), в таблице — только ссылка.

## 3. Таблицы и поля

| Таблица           | Назначение                                              |
| ----------------- | ------------------------------------------------------- |
| `characters`      | персонаж, промпты, цели 8 SFW / 23 NSFW, настройки генерации |
| `images`          | кадр, статус, review-поля, метаданные генерации          |
| `generation_jobs` | очередь заданий агента (QUEUED → COMPLETED)             |
| `packs`           | собранный пак из 31 кадра, превью, архив                |

## 4. Причины отказа

`anatomy` анатомия · `face` лицо · `pose` поза · `background` фон ·
`composition` композиция · `cropping` кадрирование · `duplicate` дубликат ·
`character` персонаж · `other` другое.

Можно выбрать несколько; первая сохраняется также в legacy-поле
`reject_reason` для совместимости.

## 5. Этапы внедрения AI

1. **Manual** — текущее состояние, решает только человек.
2. **Observer** — AI оценивает кадр и пишет `ai_decision` / `ai_score`, но ни
   на что не влияет; сравниваем с решениями человека.
3. **Assisted** — AI подсвечивает рекомендацию в интерфейсе отбора, человек
   подтверждает одним тапом (`decision_source = 'human_override'` при
   несогласии).
4. **Auto** — AI сам отклоняет явный брак, человек смотрит только спорные.

## 6. Примеры запросов к AI

- «Оцени кадр по критериям: анатомия, лицо, поза, фон, композиция,
  кадрирование. Верни score 0–1 и список проблемных категорий.»
- «Насколько кадр похож на уже отобранные кадры пака? Верни оценку дубликата.»

## 7. Логика оценки

Итоговая оценка = качество кадра × уникальность внутри пака. Кадр, близкий по
композиции к уже отобранным, штрафуется, чтобы пак был разнообразным.

## 8. Планы

- Ограничение количества необработанных кадров (сделано: лимит 6).
- Обучение на накопленных `reject_reasons`.
- Автоподбор превью и обложки из отобранных SFW.
